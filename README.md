# 🛠️ App Builder - Конструктор приложений

Визуальный конструктор приложений с возможностью сборки .APK (Android) и .EXE (Windows).

## ✨ Возможности

- 🎨 **Визуальный редактор** - drag & drop интерфейс
- 📱 **Шаблоны приложений** - калькулятор, список задач, визитка, галерея
- 🎯 **Настройка темы** - цвета, шрифты, иконки
- 📦 **Экспорт проекта** - готовый код для сборки
- 🤖 **Сборка .APK** - через Capacitor (Android)
- 💻 **Сборка .EXE** - через Electron (Windows)
- 🌐 **PWA** - веб-приложение, устанавливаемое на телефон

## 🚀 Быстрый старт

### 1. Веб-версия (без установки)

Просто открой `index.html` в браузере и создавай приложения!

### 2. Локальный запуск

```bash
# Клонируй репозиторий
git clone https://github.com/aartem2409a-pixel/app-builder.git
cd app-builder

# Запусти локальный сервер
python -m http.server 8000

# Открой в браузере
open http://localhost:8000
```

## 📱 Сборка .APK (Android)

### Требования
- Node.js 16+
- Android Studio
- Java JDK 11+

### Инструкция

```bash
# 1. Установи зависимости
npm install

# 2. Создай приложение в конструкторе и экспортируй
# (нажми "Экспорт" в веб-интерфейсе)

# 3. Перейди в папку с экспортированным приложением
cd my-app

# 4. Добавь Android платформу
npx cap add android

# 5. Синхронизируй файлы
npx cap sync android

# 6. Открой в Android Studio
npx cap open android

# 7. В Android Studio: Build → Build Bundle(s) / APK(s) → Build APK(s)
```

## 💻 Сборка .EXE (Windows)

### Требования
- Node.js 16+
- Windows 10/11

### Инструкция

```bash
# 1. Установи зависимости
npm install

# 2. Создай приложение в конструкторе и экспортируй

# 3. Перейди в папку с экспортированным приложением
cd my-app

# 4. Собери .EXE
npm run build:win

# 5. Готово! Файл .exe будет в папke dist/
```

## 📖 Использование

### Создание приложения

1. **Выбери шаблон** или начни с нуля
2. **Настрой дизайн** - цвета, шрифты, иконки
3. **Добавь контент** - тексты, изображения, кнопки
4. **Предпросмотр** - проверь как выглядит приложение
5. **Экспорт** - скачай готовый проект

### Шаблоны

- 🧮 **Калькулятор** - простой или научный
- ✅ **Список задач** - todo list с категориями
- 💼 **Визитка** - персональная страница
- 🖼️ **Галерея** - альбом фотографий
- 🍳 **Рецепты** - книга рецептов
- 📊 **Дашборд** - панель с виджетами

## 🛠 Технологии

- **Frontend**: HTML5 + CSS3 + Vanilla JavaScript
- **Mobile**: Capacitor (обёртка для Android/iOS)
- **Desktop**: Electron (обёртка для Windows/Mac/Linux)
- **PWA**: Service Worker для оффлайн работы
